# GIRO APP

Sistema web simples para controlar estoque, investimento, preco de venda, lucro previsto e produtos vendidos.

## Como usar

Abra o arquivo `index.html` no navegador. O app salva os dados no proprio navegador usando `localStorage`.

## Funcoes

- Cadastro de produto com foto.
- Edicao e exclusao.
- Marcacao de produto como vendido.
- Busca, filtro por status e ordenacao.
- Resumo de investido, venda prevista, lucro previsto e lucro realizado.
- Exportacao dos dados em JSON.

## Publicar no GitHub Pages

1. Abra as configuracoes do repositorio.
2. Entre em `Pages`.
3. Em `Deploy from a branch`, selecione a branch `main`.
4. Escolha a pasta `/root`.
5. Salve e aguarde o link ficar disponivel.
